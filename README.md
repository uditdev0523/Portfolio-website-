# 🚀 Alex Dev | Animated Professional Portfolio Website

A futuristic, high-performance, dark-mode glassmorphic developer portfolio featuring interactive canvas particle effects, custom accent theme selector, 3D tilt cards, dynamic typing header, interactive project quick view modals, and full-stack skill matrices.

---

## ✨ Features

- **🌐 Futuristic Aesthetics & Glassmorphism**: Glowing radial background spheres with custom backdrop filters.
- **🎨 Interactive Accent Color Switcher**: Toggle real-time accent themes (Cyber Cyan, Neon Purple, Emerald Green, Crimson Red, Amber Gold).
- **✨ Particle Canvas Engine**: Interactive node network background that reacts dynamically to mouse movement.
- **⚡ Smooth Typing & Scrolling**: Dynamic typing headline, scroll spy navigation, and section animations.
- **🛠️ Tech Stack & Projects Filter**: Category filterable skills & project showcase with interactive modal dialogs.
- **📱 Fully Responsive**: Tailored for Mobile, Tablet, Desktop, and Ultra-wide screens.
- **✉️ Interactive Contact Form**: Real-time client-side validation and toast notification engine.

## 🌐 How to Deploy Live on GitHub Pages (Step-by-Step)

Follow these simple steps to make your portfolio website **LIVE** on the internet with a permanent link!

### Step 1: Create a Repository on GitHub
1. Go to [GitHub.com](https://github.com) and log into your account.
2. Click the **`+`** icon in the top right corner and select **New repository**.
3. Name your repository: `portfolio-website` (or `my-portfolio`).
4. Leave it **Public**.
5. Do NOT check "Initialize with README" (we already have a complete codebase ready).
6. Click **Create repository**.

### Step 2: Push Local Code to GitHub
Open your terminal in this project directory (`C:\Users\Lenovo\.gemini\antigravity\scratch\portfolio-website`) and run:

```bash
# 1. Initialize Git
git init

# 2. Stage and commit all files
git add .
git commit -m "Initial commit: Animated Portfolio Website"

# 3. Rename branch to main
git branch -M main

# 4. Link to your GitHub repository (Replace YOUR-USERNAME with your actual GitHub username)
git remote add origin https://github.com/YOUR-USERNAME/portfolio-website.git

# 5. Push code to GitHub
git push -u origin main
```

### Step 3: Enable Free GitHub Pages Live Hosting
1. Go to your repository page on GitHub: `https://github.com/YOUR-USERNAME/portfolio-website`
2. Click on **Settings** (top navigation tab).
3. On the left sidebar, click on **Pages**.
4. Under **Build and deployment**:
   - Source: Select **Deploy from a branch**.
   - Branch: Select **`main`** branch and folder **`/ (root)`**.
5. Click **Save**.

🎉 **Within 1-2 minutes, GitHub will generate your live public link**:
`https://YOUR-USERNAME.github.io/portfolio-website/`
